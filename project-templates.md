# Project templates

[← Dynamic variables](dynamic-variables.md) · [Guide home](README.md) · [Next: Description tools →](description-tools.md)

A project template stores reusable Bulk Editor settings, including field modes, chosen values, properties and template variables. It does not save a Marketplace listing by itself.

> **Screenshot placeholder:** Template editor with a demonstration collection template (`images/project-templates.png`).

## Save and reuse

1. In **Bulk Editor**, configure the draft for a collection, then click **Save current**. Give it a recognizable name, such as “Luna clothing collection.”
2. Later, choose it from **Choose a saved template**. The template fills the editor; inspect the selected products and values.
3. Use **Template editor** to create, edit, apply or delete templates. The editor can add a saved **Variable library** set and load category choices from Marketplace.
4. Run **Review changes** before any save or publication. A template can carry an old price or category that is wrong for a new product.

For a category in **Set** mode, choose a valid Marketplace category. For a **Demo Item** in **Set** mode, choose a result from Marketplace search. The editor checks these before saving the template. Deletion has a second **Confirm delete** step.

Templates are stored locally for the current merchant in this Chrome profile. If extension data is cleared or the extension is removed, they may be lost. See [FAQ](faq.md#where-are-templates-and-history-stored).
