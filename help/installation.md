# Установка Listora Studio

[← К началу](README.md) · [Далее: активация →](activation.md)

Понадобятся Google Chrome и доступ к Second Life Marketplace. Если у вас есть готовая папка расширения с файлом `manifest.json`, Node.js не нужен. Для сборки из исходников нужен Node.js **20 или новее**.

## Вариант 1: у вас есть готовая сборка

Распакуйте полученный архив. Найдите папку, внутри которой лежат `manifest.json`, `content.js`, `background.js`, `popup.html` и `studio.css`. Это папка расширения; при установке выбирайте **её**, а не архив и не родительскую папку.

> В GitHub-архиве исходного кода папки `dist` нет: она исключена из репозитория и создаётся при сборке. Если издатель приложил готовую сборку отдельно, используйте именно её.

## Вариант 2: сборка из исходников GitHub

1. Скачайте исходный код репозитория через **Code → Download ZIP** и распакуйте его либо клонируйте репозиторий. [Инструкция GitHub по загрузке файлов](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-files-from-github).
2. Откройте терминал в корне проекта, рядом с `package.json`.
3. Выполните:

   ```sh
   npm install
   npm run build
   ```

   В Windows PowerShell, если запуск `npm` запрещён политикой сценариев, используйте `npm.cmd install` и `npm.cmd run build`.
4. После сборки проверьте, что появился файл `dist/manifest.json`.

## Загрузка в Chrome

1. Откройте новую вкладку и введите в адресной строке `chrome://extensions`.
2. Включите **Developer mode** («Режим разработчика»).
3. Нажмите **Load unpacked** («Загрузить распакованное расширение»).
4. Выберите папку готовой сборки или `dist`, полученную на предыдущем шаге.
5. Убедитесь, что появилась карточка **Listora Studio**. При желании закрепите значок через меню расширений Chrome.

Это соответствует [официальной процедуре Chrome](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked). После установки [активируйте лицензию](activation.md).

## Обновление

Если расширение установлено через **Load unpacked**, скачайте новую версию исходников или готовой сборки. Для исходников повторите `npm install` и `npm run build`, затем откройте `chrome://extensions` и нажмите **Reload** на карточке Listora Studio. Обновите вкладку Marketplace.

Кнопка **check for update** в окне расширения запрашивает у Chrome проверку обновлений; она не скачивает новую сборку из этого репозитория. Для распакованной установки обновляйте файлы вручную.

Не удаляйте установленное расширение ради обычного обновления: шаблоны, библиотека переменных и история публикаций хранятся локально в его хранилище браузера.
