# Quick Fill

[← Product Editor](product-editor.md) · [Guide home](README.md) · [Next: Languages →](languages-translation.md)

**Quick fill** uses Marketplace's existing-listing chooser to copy data into the product form. It is useful when a new color or size shares most details with a prior listing.

> **Screenshot placeholder:** Marketplace's Quick fill chooser with demonstration search results (`images/quick-fill.png`).

1. Open a listing's **Edit Item Listing** page and choose **Quick fill** in Studio.
2. Search or select the existing listing in the Marketplace chooser. The enhanced chooser supports search, recent choices and keyboard selection.
3. Let Studio reread the native form, then inspect each tab. The status message says that fields were copied.
4. Change details specific to this listing, such as title, price, images and product features.
5. Click **Update listing** only after the review.

**Example:** Copy a prior “Luna Dress — Black” listing when preparing “Luna Dress — Red,” then replace the color-specific title, description and images. Copying fields can also copy values that you did not intend to reuse. Quick Fill itself does not submit the listing.

If the chooser or copied fields do not appear, switch to **Original** and inspect Marketplace's own controls. See [troubleshooting](troubleshooting.md).
