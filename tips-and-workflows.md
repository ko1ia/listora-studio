## A safe first run

1. Edit one existing product in [Studio](product-editor.md) and reload it to verify the saved value.
2. In [Bulk Editor](bulk-editor.md), select one noncritical Unlisted product and make a small change.
3. Use [Review changes](review-publishing.md) to compare before and after, then choose **Save Changes**.
4. Verify the product in Marketplace. If you intend to list it, run a one-item publication and check the **Listed** view.

## Variant collection

For “Luna Dress — Black” and “Luna Dress — Red,” use **Group by name** to inspect variants together. Keep each title, set a shared L$299 price, and use `{{color}}` only after its value is correct for each product. Save the settings as a [project template](project-templates.md) for the next collection. Read the expanded values in the final review.

## Images and localized text

Name files to make their intended products clear. In [Image Editor](bulk-image-editor.md), inspect every file-to-product match, especially when several products are checked. For a single product, [prepare the image](image-tools.md) and watch the Marketplace uploader result. Translate from completed English content only if your browser offers the feature, then review each [language tab](languages-translation.md) manually.

## Before confirming a large batch

Check selection count, price, maturity, permissions, category, Demo Item, rendered variables and all description changes. Marketplace may change its form or requirements; test a small batch after an update. Local templates and history are tied to this Chrome profile, so keep a separate record of business-critical listing decisions.
