# Frequently asked questions

[← Troubleshooting](troubleshooting.md) · [Guide home](README.md)

## Where do I get or renew a license?

Use the official Listora Studio product listing on Second Life Marketplace. Its direct URL has not yet been confirmed for this guide. The renewal route and license terms also need confirmation from the seller. If you already have a key, follow [activation](license-activation.md).

## Does Unlisted mean a new product?

No. Marketplace's **Unlisted** group can include older hidden products. **New since last scan** means only that this extension did not see the product in its earlier scan. See [Bulk Editor](bulk-editor.md).

## Does selecting a product or preparing an image make a live change?

No. Single-product edits need **Update listing**. Bulk edits need confirmation after **Review changes**. Images need **Upload to Marketplace** or **Upload all**, followed by verification on the site.

## Can I translate every listing automatically?

The single-product Studio offers browser translation only when Chrome exposes its built-in Translator feature. Results can be partial and need manual review. See [Languages and translation](languages-translation.md).

## What does Save Changes do compared with Publish Selected?

**Save Changes** updates selected product data without listing. **Publish Selected** saves and then attempts to list each selected product, with an additional Listed-view check. See [Review and publishing](review-publishing.md).

## Where are templates and history stored?

In the extension's local Chrome storage, scoped to the merchant. A new Chrome profile will not show those records. Clearing extension data or removing the extension may delete them. Publishing history keeps only the latest record for each product.

## Can I update an unpacked extension from its popup?

The popup can ask Chrome to check for updates, but an unpacked build from this repository must be replaced or rebuilt and reloaded manually. See [installation and updates](installation.md#update-an-unpacked-installation).

## Which name should I look for in Chrome?

**Listora Studio** is the name in the extension manifest and popup. “Marketplace Studio” was a working name in the documentation request.
